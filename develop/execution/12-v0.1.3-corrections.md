# 12. v0.1.3 — corrections from the 10-16 review

2026-10-16. Fixes found by `research/05`. Each was written test first.

## Kiro defers MCP too

v0.1.2 counted Kiro MCP as loaded because, as of 09-28, no documentation said otherwise. The Kiro docs published 10-13 (https://kiro.dev/docs/mcp/tool-search/) say IDE 1.3+ and CLI V3 sessions (2.31+) load MCP tools on demand. CLI V2 does so only with `toolSearch.enabled`, once either 5% of the window or 50,000 tokens is crossed (confirmed from the docs).

`kiroLoading` reads `chat.agentEngine` and `toolSearch.*` from `~/.kiro/settings/cli.json`, with the workspace copy overriding. This machine runs `v3` (confirmed).

| this machine | v0.1.2 | v0.1.3 |
|---|---|---|
| Kiro MCP in startup estimate | 8,914 | 0 (8,914 shown as "load only on use") |
| audit estimate | 25,855 | 16,577 |
| `fix` | 13,262 / 11 switches, four of them Kiro MCP | 4,464 / 9 switches, plugins only |

Not verified: which engine the IDE-backed ACP sessions report when `chat.agentEngine` is absent. Absent is treated as V3 or IDE, which defers.

## `fix` no longer loses an agent's concurrent edit

`applyPlan` used to copy and write without checking the file again. Now:

- It re-reads the file and refuses if the content differs from what the plan was built on.
- It writes a temp file in the same directory and renames it over the original, keeping the mode.
- It resolves symlinks first, because a rename would otherwise replace a dotfile link with a plain file. A test caught this before release.

## mcp-scan process handling

- `close` instead of `exit`, so the answer is read before the result settles.
- An `error` handler on stdin: EPIPE from a server that died used to be an unhandled error.
- On POSIX, servers start in their own process group and the whole group is killed. A test confirms the grandchild an `npx`-style parent starts is gone after a timeout.
- HTTP bodies are capped at the same 8 MiB as stdio.
- `clientInfo` now says `ctxmeter` with the package version. It used to say `agentlens 0.1.0`.

## Smaller

- `.ctxmeter/` writes its own `.gitignore` (`*`). Snapshots hold home paths and server names, and the directory sits in the user's repository.
- Wording: removed "MCP tool schemas are the largest reported cost" from audit and fix, and the README claims "the only tool that does" and "the part nobody else measures". `research/05` found tools that do both.
- When every measured server is deferred, mcp-scan says "none load at startup" instead of "0 tokens … 17,877 more".

Tests: Node 189 pass, Swift 50 pass, verify-package ok.
